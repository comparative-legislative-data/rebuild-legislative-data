# Archived DB1 planning reference

This folder contains DEC-0018, an unadopted pre-proxy plan for capture,
native access, and DB1. The proxy MVP closed after that plan was prepared, so
it is retained for audit and design context only.

The project needs a new owner-approved DB1 planning/implementation proposal
before any source-data capture, database change, or DB1 build. Start from
[`docs/data/gb-sct/README.md`](../../../../data/gb-sct/README.md).
