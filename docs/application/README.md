# Application status

The private-beta access MVP is deployed and owner-tested for application,
approval, activation, password login, magic-link login, password change,
sign-out, and superuser separation. It remains a private access-control layer,
not a data release.

The application currently exposes the accepted upstream-proxy MVP only. It
does not contain DB1 captures, DB2 canonical data, downloads, charts, or public
research-data access. DEC-0077 has deployed one [restricted DB1 preview](../data/gb-sct/GB_SCT_DB1_FIRST_PROJECTION_AND_PRIVATE_EXPLORER_RESULT_DEC0077_2026-08-03.md)
for active beta users and superusers, pending independent owner acceptance. It
is a single retained projection, not generic DB1 or research-data access.

The detailed access-control and implementation records are retained in
[`docs/archive/application/private-beta-mvp/`](../archive/application/private-beta-mvp/).
Future DB1 interface work requires its own approved package and independent
front-end acceptance.
